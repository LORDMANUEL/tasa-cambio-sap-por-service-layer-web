# Multipaís y monedas

- La zona horaria se configura con un identificador IANA.
- Las fuentes guardan un campo `country` descriptivo.
- Cada CompanyDB usa `currencies_csv`, por ejemplo `USD,EUR` o `USD,GTQ`.
- SAP Business One determina su moneda local con Service Layer.
- Cada CompanyDB puede usar un Service Layer/OData diferente.
