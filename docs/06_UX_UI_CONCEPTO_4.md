# UX/UI — Concepto 4

La interfaz V5 implementa el **Dashboard Integrado** seleccionado:

- sidebar corporativa;
- topbar con usuario, tema y recorrido;
- KPI cards;
- tarjetas de estado de sincronización;
- tablas contables;
- modo oscuro/claro;
- proceso modal animado con Banco → Validación → SAP → Comparación → Escritura → Verificación → Registro;
- bitácora visual durante procesos;
- recorrido guiado;
- responsive;
- branding dinámico.

El objetivo es que Contabilidad pueda entender en segundos qué tasa se tomó, qué encontró SAP, qué se cambió, qué falló y cuándo vuelve a ejecutarse.
